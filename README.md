# 🏦 Simple Bank Management System

A beginner-friendly **Python Bank Management System** that allows users to create bank accounts and perform basic banking operations through a command-line interface.

## ✨ Features

- 🆕 **Create Account:** Create a new account using a unique account name.
- 💰 **Check Balance:** View the current balance of an account.
- 📥 **Deposit Money:** Add money to an existing account.
- 📤 **Withdraw Money:** Withdraw money while checking for sufficient balance.
- 🛡️ **Input Validation:** Prevent invalid deposit and withdrawal amounts.

## ⚙️ Requirements

- Python 3.x

## 🚀 How to Run

1. Save the Python code in a file named `bank.py`.
2. Open a terminal in the project directory.
3. Run the following command:

```bash
python bank.py
```

## 📋 Available Operations

| Command    | Description                           |
| ---------- | ------------------------------------- |
| `show`     | Displays the current account balance. |
| `deposit`  | Deposits money into the account.      |
| `withdraw` | Withdraws money from the account.     |

## 📝 Notes

- Each newly created account starts with a balance of `0`.
- Account information is stored in a Python dictionary.
- Data is stored temporarily in memory and will be lost when the program closes.
- This project demonstrates basic Python concepts such as classes, functions, dictionaries, loops, and conditional statements.
